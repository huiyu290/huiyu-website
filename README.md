# 惠瑜 · 个人网站（银河系简历）

用于电商运营 / 市场营销岗位简历投递的个人网站。以「旋转的银河系」为视觉核心：
黑色背景上漂浮淡淡的银色粒子，八大行星（粒子星球）围绕中心太阳缓慢旋转，
鼠标悬停银河系时暂停旋转，并在外沿以银色粒子文字显示星球名，点击星球查看对应内容。

## 快速开始

### 方式一：直接打开
双击 `index.html`，用 Chrome / Edge 打开即可（大部分功能可用）。

### 方式二：本地服务器（推荐，视频加载更稳定）
```powershell
powershell -ExecutionPolicy Bypass -File .\start-server.ps1
```
然后浏览器访问：http://localhost:8080

> 服务器为单进程简易实现，大视频支持顺序播放；如需完整拖拽进度，可改用任意静态服务器
> （如 `npx serve`、VS Code Live Server、GitHub Pages 等）。

## 内容维护指南

### 补充图片（项目经历 / 教育背景）
页面中所有「🖼️ 图片待补充」占位块，在 `js/content.js` 中对应的 `imgSlot('说明')`
调用处，把占位块替换成图片即可，例如：

```html
<img src="作品集/marketing/xxx.png" style="width:100%;border-radius:10px;margin-top:14px;" alt="活动海报">
```

代码中也在每个图片位上方留了 `<!-- 🖼 图片位（...） -->` 注释，方便定位。

### 新增作品集项目
1. 在 `js/content.js` 的 `MEDIA` 对象中登记文件路径；
2. 在 `venusPanel()` 中按现有 `.project` 卡片格式添加一项（视频 → 一句介绍 → 摘要 → 下载按钮）。

### 新增 / 调整星球
在 `js/galaxy.js` 的 `PLANET_DEFS` 中配置：
`key`（对应 content.js 的 PANELS 键）、`name`、`orbit`（轨道半径比例）、
`size`（半径比例）、`color`（silver / blue）、`ring`（是否带光环）、`type`（tab / soon）、`spd`（公转速度）。

### 部署
纯静态站点，无任何第三方依赖。可整体上传到 GitHub Pages、Vercel、Netlify 或对象存储（OSS / COS）等任意静态托管。
注意：作品集文件较大（含视频），部署时请连同 `作品集/` 文件夹一起上传。
